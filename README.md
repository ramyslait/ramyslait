A collaborative full-stack web project for a fragrance brand, with product browsing, shopping flows, account management, and an admin dashboard.

**JavaScript · Node.js · Express · MongoDB · EJS**

### [Habibi Saniee — Home services prototype](https://github.com/ramyslait/Habibi-Saniee)
A frontend prototype covering customer bookings, technician orders, and an admin overview, supported by project planning documents.

A team game project with three themed levels, demonstrating inheritance, abstraction, game interactions, and JavaFX interfaces.

**Java · JavaFX · Object-oriented programming**

An exploration of brute-force and divide-and-conquer approaches, with C++ implementations, a research paper, and an interactive visualizer.

**C++ · Algorithm analysis · HTML**

A team video-player project with playlist management built around a doubly circular linked list.

**C++ · WinForms · Data structures**
